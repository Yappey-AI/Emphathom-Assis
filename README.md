## What Is Emphathom?

Emphathom is a personal AI assistant I am building from scratch.

But it is not just a project. It is a question.

For as long as I can remember, I have felt that nobody truly understands me. I am a deep observer — I read people, situations, and rooms in ways most people don't notice. And what I usually see is that most people don't really see me back.

One person came closest. That person changed everything for me — made me want to become better, pushed me toward faith, toward ambition, toward this. Even they couldn't reach the full of me. Not because they didn't try. Because some part of me is still unknown — even to myself.

So I decided to build something and ask it directly:

**Will you be able to understand me?**

I already know the answer is probably no. An AI cannot feel. It cannot truly know a person. But I am asking anyway. Because the question matters more to me than the answer. And because building something that attempts the impossible — that is the most honest thing I know how to do.

I named it Emphathom. A word that exists nowhere else in the world except in my mind, and now in this repository.

## What Emphathom Does (Current Stage)

Emphathom is in its early development phase. I started coding from absolute zero — I had never written a single line of code before this project.

**Currently built:**
- Voice and text input recognition
- Natural language understanding using if/elif logic
- Personalized responses using the user's name
- Clean function-based architecture (greet, get_name, get_activity, respond, main)
- Continuous conversation loop using while True
- Graceful exit on goodbye commands

**Currently learning and building toward:**
- AI brain integration using Claude API or OpenAI API — so Emphathom can understand any input, not just pre-coded responses
- Voice output using pyttsx3 or ElevenLabs — so Emphathom speaks back
- System commands — open applications, set timers, check time
- Browser automation using Selenium — so Emphathom can navigate the web, open Instagram, send messages by voice command
- Memory system — so Emphathom remembers past conversations and user preferences
- Wake word detection — so Emphathom is always listening
